# 📈 주식 추세 분석기 (Stock Trend Analyzer)

주식 매매 전에 **해당 종목이 지금 어떤 추세(상승 / 하락 / 횡보)에 있는지** 자동으로 판정하고,
이동평균·RSI·MACD·볼린저밴드·매매 신호·지지/저항선을 한 화면에서 보여주는 Streamlit 대시보드입니다.

미국 주식(`AAPL`, `TSLA` …)과 한국 주식(`005930` / `005930.KS`, 코스닥 `035720.KQ`)을 모두 지원합니다.

> ⚠️ **면책 고지** — 본 도구는 기술적 지표 기반의 **참고용 분석**이며, 투자 자문이나 매매 지시가
> 아닙니다. 데이터는 지연·오류가 있을 수 있으며, 모든 투자 판단과 그 책임은 사용자 본인에게 있습니다.

## 주요 기능

- **자동 추세 판정** — 이동평균 배열(정/역배열), 가격 위치, 단기 이평 기울기를 종합해
  상승🟢 / 하락🔴 / 횡보🟡 + 신뢰도(%) + 근거 문장으로 표시
- **캔들 차트** — SMA(단·중·장기), 볼린저밴드, 골든/데드크로스 마커, 지지/저항선 오버레이
- **보조지표** — RSI(14), MACD(12/26/9) 서브플롯
- **규칙 기반 매매 신호** — 이평 교차·RSI·MACD·볼린저를 점수화해 매수 관심 / 중립 / 매도 관심 종합
- **오프라인 데모 모드** — 네트워크가 없어도 합성 데이터로 UI 확인 가능

## 설치 & 실행

```bash
# 1) (권장) 가상환경
python -m venv .venv && source .venv/bin/activate

# 2) 의존성 설치
pip install -r requirements.txt

# 3) 앱 실행
streamlit run app.py
```

브라우저에서 열린 뒤, 왼쪽 사이드바에 티커를 입력하세요.
네트워크가 막힌 환경이라면 사이드바의 **"🧪 데모 데이터 사용"** 을 켜면 합성 데이터로 화면을 볼 수 있습니다.

## 프로젝트 구조

```
.
├── app.py                  # Streamlit 진입점 (UI, 차트, 레이아웃)
├── src/

│   ├── trend.py            # 추세 판정 + 골든/데드크로스 탐지
│   ├── signals.py          # 규칙 기반 매수/매도 신호

├── tests/

└── requirements.txt
```

## 추세 판정 방식

세 가지 근거를 각각 `-1 ~ +1` 점수로 계산해 평균합니다.

1. **이동평균 배열** — 단기 > 중기 > 장기(정배열)면 +, 반대(역배열)면 −.
   가격의 2% 이내로 붙어 있는 이평은 "의미 없는 차이"로 보아 횡보로 판정(데드밴드).
2. **가격 위치** — 종가가 각 이동평균 위/아래에 있는 정도.
3. **단기 이평 기울기** — 최근 20봉 선형회귀 기울기.

종합 점수가 `+0.25` 초과면 **상승**, `−0.25` 미만이면 **하락**, 그 사이면 **횡보** 입니다.

## 테스트

```bash
python -m pytest tests/ -q
```

네트워크 없이 합성 시계열로 지표 계산식·추세 판정·신호·지지저항 로직을 검증합니다.

## 데이터 소스에 대한 참고

기본 데이터는 무료·지연 소스인 **yfinance**(Yahoo Finance)를 사용합니다. 실시간 시세가 아니며,
일부 사내/클라우드 환경에서는 Yahoo 도메인이 방화벽으로 막혀 조회가 실패할 수 있습니다.
그 경우 로컬 PC에서 실행하거나 데모 모드를 사용하세요. 실시간 데이터가 필요하면 증권사/데이터
벤더 API로 `src/data.py` 의 `fetch_ohlcv` 를 교체하면 됩니다.
